# Identidad de marca — THE WOLF

## Nombre

**THE WOLF**

El nombre representa la idea de un lobo como símbolo de inteligencia, adaptación, seguridad y capacidad para resolver problemas. La marca toma esta idea y la relaciona con el mundo de la tecnología y el soporte informático.

## Slogan

**Tecnología & Soporte**

El slogan resume las dos áreas principales del emprendimiento: la venta de productos tecnológicos y la prestación de servicios de reparación, mantenimiento y soporte.

## Misión

Brindar productos y soluciones tecnológicas accesibles y confiables, ofreciendo venta, reparación, mantenimiento y soporte para computadoras, celulares y otros dispositivos.

## Visión

Construir una marca reconocida por la confianza, la buena atención y la capacidad de resolver problemas tecnológicos de manera clara y profesional.

## Personalidad de la marca

THE WOLF busca transmitir una personalidad:

* **Profesional:** trabaja de manera ordenada y responsable.
* **Tecnológica:** utiliza herramientas y soluciones.
* **Confiable:** busca generar seguridad en cada servicio.
* **Directa:** comunica las soluciones de forma clara y sencilla.
* **Moderna:** utiliza una identidad visual actual.

## Público objetivo

El emprendimiento está dirigido principalmente a:

* Personas que necesitan comprar computadoras, celulares.
* Usuarios que necesitan reparar sus dispositivos.
* Personas que necesitan instalar o configurar software.
* Usuarios que necesitan ayuda para resolver problemas tecnológicos.

## Propuesta visual

El logo representa la cabeza de un lobo mediante formas modernas. Se utiliza un estilo sólido y tecnológico para diferenciarlo de una representación tradicional del animal.

La combinación de negro y tonos metálicos busca transmitir una imagen moderna, profesional y tecnológica.

El logo puede utilizarse en:

* Sitio web.
* Redes sociales.
* Documentación.
* Publicidad.
* Tarjetas y material gráfico.
* Imágenes de productos y servicios.

## Versiones del logo

### Logo principal

La versión principal utiliza el símbolo del lobo acompañado por el nombre **THE WOLF** y el slogan **TECNOLOGÍA & SOPORTE**.

### Logo reducido

Para espacios pequeños se utilizará principalmente el símbolo del lobo, sin necesidad de incluir todo el texto.

### Uso sobre fondos

El logo está pensado principalmente para fondos oscuros, aunque deberá contar con una versión que mantenga una buena legibilidad sobre fondos claros.

## Paleta de colores

| Color           | HEX       | Uso                                      |
| --------------- | --------- | ---------------------------------------- |
| Negro           | `#0B0B0B` | Fondo principal y elementos de contraste |
| Gris carbón     | `#252525` | Fondos secundarios y componentes         |
| Plata metálica  | `#C0C0C0` | Elementos del logo y detalles visuales   |
| Dorado metálico | `#D4AF37` | Destacados y elementos de identidad      |
| Blanco          | `#FFFFFF` | Textos y contraste                       |

La paleta combina tonos oscuros con colores metálicos para mantener una identidad visual relacionada con la tecnología y transmitir una imagen profesional.

## Tipografía

### Tipografía principal

**Montserrat**

Se utilizará principalmente para textos, botones, información de productos y contenido general del sitio. Es una tipografía clara y fácil de leer.

### Tipografía secundaria

**Orbitron**

Se utilizará en títulos destacados y elementos específicos de la identidad visual para reforzar la estética tecnológica de la marca.

## Tono de comunicación

THE WOLF utilizará un tono:

* Claro y directo.
* Profesional pero fácil de entender.
* Cercano con el cliente.
* Orientado a resolver problemas.
* Sin utilizar términos técnicos innecesarios cuando puedan explicarse de forma sencilla.

La comunicación debe transmitir confianza y evitar promesas exageradas o información que no haya sido confirmada.

## Valores

Los principales valores de THE WOLF son:

1. **Confianza**
2. **Responsabilidad**
3. **Transparencia**
4. **Buena atención**
5. **Solución de problemas**
