# Diseño de interfaz — THE WOLF

## 1. Objetivo del diseño

El diseño del sitio web de THE WOLF busca transmitir profesionalismo, confianza y una identidad relacionada con la tecnología. La interfaz deberá ser moderna, clara y sencilla de utilizar, tanto desde una computadora como desde un celular.

## 2. Identidad visual

La interfaz utilizará la identidad definida para la marca.

| Elemento              | Definición                              |
| --------------------- | --------------------------------------- |
| Negro `#0B0B0B`       | Fondo principal y elementos destacados. |
| Gris carbón `#252525` | Tarjetas y secciones secundarias.       |
| Plata `#C0C0C0`       | Detalles gráficos y elementos del logo. |
| Dorado `#D4AF37`      | Botones destacados y acentos visuales.  |
| Blanco `#FFFFFF`      | Textos principales y contraste.         |

La tipografía principal será Montserrat. Orbitron podrá utilizarse en algunos títulos para reforzar el estilo tecnológico, evitando sobrecargar la interfaz.

## 3. Componentes de la interfaz

* **Encabezado:** logo y menú de navegación.
* **Sección principal:** presentación de THE WOLF y acceso al catálogo.
* **Tarjetas de productos:** imagen, nombre, descripción breve y precio.
* **Botones de acción:** acceso al catálogo, contacto y pedido.
* **Pie de página:** información del emprendimiento y medios de contacto.

Los componentes mantendrán colores, tamaños y estilos coherentes en todas las páginas.

## 4. Páginas principales

### Página de inicio

Presentará el logo, el nombre THE WOLF, el slogan “Tecnología & Soporte” y una introducción a la propuesta del emprendimiento. También incluirá accesos al catálogo y a los servicios.

### Catálogo de productos

Mostrará productos organizados por categorías. Cada tarjeta incluirá una imagen ilustrativa, el nombre, una descripción breve y un precio de ejemplo.

### Servicios

Presentará los servicios de mantenimiento, reparación, instalación de software, configuración de dispositivos y soporte técnico.

### Contacto

Ofrecerá medios de contacto y acceso a WhatsApp para realizar consultas. 

### Carrito

Permitirá reunir productos seleccionados y preparar un resumen para enviar por WhatsApp. No tendrá procesamiento de pagos ni confirmación automática de stock.

## 5. Adaptación a dispositivos

El sitio se diseñará para funcionar en computadoras, tablets y celulares. En pantallas pequeñas, el contenido se reorganizará para facilitar la lectura y el uso de los botones.

Se utilizarán reglas CSS adaptables, como consultas de medios (*media queries*), para modificar la distribución según el ancho de pantalla.

## 6. Usabilidad y accesibilidad

* Utilizar textos claros y fáciles de comprender.
* Proporcionar descripciones alternativas a las imágenes.
* Usar botones con nombres que indiquen su función.
* Mantener una navegación consistente entre páginas.
* Evitar elementos visuales innecesarios que dificulten la lectura.

## 7. Criterio general

La propuesta visual combinará una estética oscura con detalles metálicos y dorados, sin sacrificar la legibilidad. La identidad se mantendrá consistente en el sitio, las publicaciones y los materiales digitales del emprendimiento.
